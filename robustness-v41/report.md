### 3.3 极端盈利单法医：2026-07-26 多头（毛 +22.07R、净 +21.50R）

全文见 `forensic_max_trade.txt`。摘要：

- **信号真实**：信号根 2026-07-26 08:30 UTC（O 1879.84 / H 1881.38 / L 1879.04 / C 1881.03）。
  1H 严版趋势为多（高点台阶 4.69、12.25，低点台阶 13.28、3.05，均 ≥ 0.5×ATR(1h)=2.79）。
- **关键带真实**：交易带为阻力带 (1880.93, 1881.17)，4 次有效触碰；96 根内同侧
  “above”到达恰好 2 次（第 2 次即信号根），踩线达标，无放水。
- **信号 K 真实**：信号根内最后一根 5m 为看涨吞没（O 1879.88 → C 1881.03）。
- **成交档差异真实**：成交根 08:45 最低 1880.42，触及限价 1881.03（T0 成交），
  但未穿透 T1 阈值 1880.09 与 T2 阈值 1879.15——**该单只在 T0 档存在是价格事实，
  不是模型 artifact**。三根 5m 均触及限价，maker 排队轮到与否是运气问题。
- **出场路径真实**：从成交后一根起连续 100+ 根无止损触及（止损 1878.03，
  成交根最低 1880.42，仅高出 2.39 点——开局即贴止损边缘），价格一路走高至
  ~1971（次日 06:30），2026-07-27 12:15 收盘 1947.28 跌破 EMA50 出场，持仓约 27.8h。
- **数据质量**：零值/NaN 扫描干净；信号根与成交根的 15m OHLC 与 5m 聚合逐项一致；
  当日波幅 93.97（5.00%） vs 前 90 日中位 72.17——活跃日而非异常日。
- **结论：该单不是坏 K 线、跳空或数据错误造成的假单，而是一段真实趋势腿
  （1881→1971）叠加一个 0.16% 的极紧止损放大的结果。** 它的脆弱性不在真实性，
  而在可重复性：0.16% 止损意味着任何一根 5m 的正常抖动都可能让它以 −1R 结束，
  且它在 T1/T2 档根本不存在——把系统期望押在这种单上，就是押运气。

### 3.4 时间顺序与同根冲突

- 止损只能在成交之后判定（成交 bar 内止损须 5m 排序校验，见 §1.3）。
- 每根 15m 内先 3 根 5m 判止损、再 15m 收盘判 EMA；同根两者同时触发时**止损优先**。
- 样本内实测：成交 bar 内止损 3 单排序全部有效，违规 0 起。
- 样本外实测（T0 档）：341 单中 169 单纸面出场落在成交 bar 内（止损 13 + EMA 156），
  按执行器口径全部重算；其中止损 13 单经 5m 排序校验：11 单有效保留、2 单违规重算。
  重算对毛总的影响仅 −2.07R，不改变方向。

## 4. 第三阶段：统计稳健性

方法：逐笔净 R，Bootstrap ≥ 20,000 次（固定种子 20261025），报告均值 95% CI
与净期望为负的模拟比例；含最大单与去最大单两套；区块 Bootstrap（保留交易顺序，
移动块 + wrap，块长 3/5/10/20）作补充——块长 5 约对应 1–2 个月的交易簇
（样本内约 1 单/8 天），敏感性以 3/10/20 对照；集中度报告最大单占比、前 5 单占比
与凑齐 50%/90% 正收益所需的单数。

| 前 5 单正收益合计 | 23.66R（占净亏绝对值的 28.9%） | 39.02R（占净总的 167.6%，即亏损吃掉 67.6% 的尾部利润） |
| 凑齐 50% 正收益所需单数 | 10 单 | 1 单 |
| 凑齐 90% 正收益所需单数 | 40 单 | 4 单 |
| 胜率 | 26.7%（91/341） | 32.6%（15/46） |

关键辨析：样本外失败**不是“缺尾部”**——样本外利润本身就是分散的
（90% 正收益要 40 单凑），却仍然净亏 −82R。也就是说，v4.1 在未见数据上
既没有尾部可依赖，也没有底部可支撑：胜率 26.7% 下平均亏损把平均盈利吃光
还有余。这比样本内的“尾部集中”诊断更严重：样本内至少还有一个可争论的
尾部故事，样本外连这个故事都没有。

## 5. 第四阶段：最终决策

**C — 建议暂停 v4.1。**

逐条对照事前决策标准（§1.4）：

- C 条件 1（样本外 T0 净均值 < 0）：−0.2405，满足。
- C 条件 2（去最大单后亦 < 0）：−0.26，满足。
- C 条件 3（T1/T2 亦为负）：−0.3118 / −0.3421，满足。
- A 的任一条件均不满足：T1 均值 < 0、去最大单 < 0、Bootstrap CI 下界 < 0。
- B 不适用：B 要求“无法证明优势、但也尚不能充分否定”；此处 341 单样本外、
  20 套 Bootstrap 全部 P(均值<0) = 1.0000、6 年份与 4 regime 全负，已构成
  充分否定——不是“证据不足”，是“证据指向否定”。

**暂停的具体含义（供用户定夺，不由本报告越权）：**

1. 不再以“攒前向 50 单判读”为默认路径消耗验证资源：按样本外均值，
   50 单前向的期望成本约 −12R（约 −13.5U，占 56U 本金约 24%），且无证据
   表明前向会与 5.8 年样本外背离。
2. live 执行器去留由用户另行定夺；本报告只负责策略证据，不碰 live 配置。
   若用户选择继续跑 live，必须明确其性质已从“验证”转为“已知负期望下的
   个人选择”，不再以“攒样本判读”为理由。
3. 若将来重启 v4.1 族策略，重启门应为：在**新的、未参与此次验证的**
   前向数据上先证明正期望（例如先跑小样本纸面且 T1 档为正），而非回头再调
   样本内参数——本次 341 单样本外已经用完，再调参只会把样本外也变成样本内。

**本报告不建议的方向**：不要对 v4.1 做参数微调后重新声称“改进版”
（那将是对同一批数据的又一次筛选）；不要把样本外 341 单并入“总样本”
去平均（那会把 46 单的尾部故事稀释成一个看起来温和的数字，却掩盖了
方向性结论）。

## 6. 假设、缺口与限制（不藏短板）

1. **EMA 出场按触发根收盘价计**（偏乐观）：真实市价成交在下一根开盘附近且有冲击；
   压力测试中的 EMA 延迟档（下一根开盘）与 EMA 滑点档即为此缺口的量化。
2. **入场统一计 maker**（偏乐观）：限价单无 postOnly，下单瞬间穿价成交可能是 taker；
   入场 taker 档即为此缺口的量化。
3. **T0 触及档成交率 100% 未计排队位置**：真实 maker 排队中仅触及未必轮到；
   穿透档（T1/T2）与排队 haircut 档即为此现实检验。
4. **资金费名义按入场名义计**，未随价格漂移（影响 < 资金费本身）；样本内资金费合计
   仅 −0.18R，非主因，样本外量级同理（见运行记录）。
5. **未建模**：20x 杠杆下的强平偏离（极端行情止损市价单滑出止损价之外，滑点档仅覆盖至 0.1%）、
   执行器 20 秒轮询延迟与信号检测延迟、maker 返佣/折扣。
6. **样本外仍非“未来”**：2020–2025 年数据未参与设计，但策略族（趋势回踩 + EMA 追踪）
   的一般思想来自公开交易教育（Rayner Teo 等），思想层面的先验污染无法完全排除；
   真正的终审仍是前向 50 单（若结论为 A 或 B）。
7. **单品种**：本验证只做 ETH；XAU/CL/QQQ 三线不在本次范围内，其 90 天回测结论不变。
8. **OOS 引擎与样本内引擎同一套代码**：样本内复现门精确通过是移植可信的证据，
   但共用代码意味着共用 bug 的风险——复现门 + 随机窗口校验 + 法医三重检查是针对此的缓解。
9. **环境事件**：2026-10-25 VM 重启清空 /tmp，致首批 OOS 缓存丢失；已改用工作区内
   `data_cache/` 持久化并重新取数、重新验证复现门（结果不变），不影响结论。
