# M2 假设-证伪登记表（第一阶段，零代码）

用途：所有待检验假设先登记、检验前写死证伪线，事后不得补写。检验数据只认冻结后前向数据；历史复用一律记为探索，不得当作检验结果。

## 登记规则（铁律）

1. 证伪线必须在检验开始前写死；检验后发现证伪线不利，不得修改口径重算。
2. 检验数据栏必须写明“冻结后前向流”及冻结时间；填“历史回测”的一律不算检验。
3. 多重性归属必填：主实验（全 family 唯一，当前建议 E2）或探索性；探索性阳性不得升级为确证结论，升级须新一轮前向数据。
4. 结论只取三档：通过 / 证伪 / 未决；样本量不足、CI 过宽时填“未决”，不得填“通过”。
5. 同一假设只检验一次；重检验须新假设 ID 并注明与旧 ID 的关系。
