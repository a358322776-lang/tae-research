# M1 结构化多空反证备忘录模板（第一阶段，零代码）

用途：任何策略审计、规则变更、研究结论在拍板前，必须先填完这张表。它是流程文档，不改 TAE 代码、不进信号链、不产生交易指令。

## 必填字段（缺一项即未完成，不得拍板）

| 字段 | 填写要求 |
|---|---|
| 研究对象 | 规则/策略/结论的名称＋版本号（如 B1 v0.1、L1 草案、E2 主实验） |
| 数据窗口 | 起止时间、时间框架、样本量；历史复用须注明“探索数据，非验证数据” |
| 正方最强论据（≤3 条） | 每条附证据出处：文件路径＋行号，或数据表＋统计口径；不许无出处论据 |
| 反方最强论据（≤3 条） | 同上；只写正方不写反方的备忘录视为未完成 |
| 裁决依据 | 裁决采信了哪几条证据、排除了哪几条、排除理由是什么 |
| 什么证据会推翻本结论 | 具体、可观测的条件（如“前向 48 根 A 率 95% CI 上限 < 对照组＋margin”）；写“更多数据”不算 |
| 数字栏 | 只许填 TAE/前向观察系统算出的确定性数字；LLM 不得编造数字，不得把描述性数字读作盈利证据 |
| 结论状态 | 只取三档：通过 / 未决 / 证伪；不许“基本成立”“大概率有效”这类模糊词 |
| 复核人 / 日期 | 填表人与复核日期 |

## 填写规则（防呆）

1. 反方栏空着不许进入裁决；证据不足时结论状态只能填“未决”，不得用“暂且通过”绕过。
2. 数字栏每一项注明口径（如“收复后 48 根、确认根时刻、A 率”），口径不同的数字不得同表比较。
3. 本备忘录只审计、不决策：它不批准任何规则变更，变更仍须用户另行拍板并冻结。
4. 示例（非结论，仅示格式）：研究对象“L1 H-A1”；反方最强论据之一“作废后原方向恢复率 48 根 63.6%、96 根 72.1%，反向交易反复面对原方向恢复（l1_events.csv，post48_resume/post96_resume）”；推翻条件“H-A1 前向检验 95% CI 上限 < 50%＋margin（margin 待冻结日定）”。
