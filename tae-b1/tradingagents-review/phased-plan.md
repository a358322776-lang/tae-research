# TradingAgents 整合分阶段方案

> **红线**：目标不是复制 TradingAgents，也不是让大模型直接下单。目标是利用其研究框架提升 MUSE 的假设生成、反证分析、策略审计和风险评估能力，同时**保留 TAE 作为独立的确定性回测与执行引擎（TAE 不读 LLM 输出、不把 LLM 结论当信号）**。
>
> 任何涉及 TAE 代码或执行的阶段都标"须用户另行批准"。本方案本身不修改任何现有文件、不部署、不交易。

---

## 第一阶段：零代码，只改文档模板（M1＋M2＋M3）

- **准入条件**：无。本阶段只是文档工作，不需要任何前置批准（用户已批准本审查报告的交付，不等于批准后续阶段；进入第二阶段前仍需按验收走）。
- **交付物**：
  1. `tradingagents-review/templates/audit-memo-template.md`——策略审计备忘录模板（必填字段：正方最强论据、反方最强论据、裁决依据、什么证据会推翻本结论、数字来源文件路径）。
  2. `tradingagents-review/templates/hypothesis-registry.md`——假设-证伪登记表（必填字段：假设陈述、预测度量、冻结日、证伪线、检验数据来源、结果、复核人；E2 与 L1 的 H-A1/H-A2/H-B1/H-C1 首批入表）。
  3. `tradingagents-review/templates/risk-checklist.md`——风险检查清单（单笔风险、总敞口、日/周熔断、杠杆上限、止损可执行性、成本计入、样本量功效、多重性 α 分配；任一项未通过即暂停）。
- **验收标准**：下一次策略审计（或实验设计审查）实际使用三份模板产出文档，且模板中的数字栏全部可追溯到 TAE/观察系统文件（抽查 3 处，0 处无来源）。
- **回滚方式**：删除三份模板文件。已产出的审计文档不受影响（它们只是 markdown）。
- **防呆**：模板里的数字栏只许填确定性数字；反方论据无可核查来源视为未完成；清单是门不是参考。

## 第二阶段：小脚本，不动 TAE 核心（M5＋M4 文档部分）

- **准入条件**：第一阶段验收通过。
- **交付物**：
  1. 一个只读脚本（新文件，放在 `tradingagents-review/` 内）：读取 TAE 纸面台账/观察系统 ledger，为每条审计结论生成"决策时已知信息"快照（数据范围、冻结版本、结算日期三字段），写入独立的审计日志目录（append-only）。
  2. 时间戳表述纪律补丁：审计报告模板中增加"缺口 vs 阴性结果"区分条款（借 `date_window.py` 的 `coverage_gap` 思想：覆盖不到的窗口报"不可用"，不是"无信号"）。
- **验收标准**：抽查 3 条历史审计记录，均可还原"决策时已知什么"（数据范围＋冻结版本＋结算日期齐全）；脚本运行前后 TAE 相关树 mtime 0 变动（沿用前向观察系统的围栏检查做法）。
- **回滚方式**：停用新格式与脚本；旧记录不受影响；审计日志目录可整体归档。
- **防呆**：脚本只读 TAE 输出文件，不 import 扫描器/执行器；反思栏只填确定性数字，不许 LLM 散文；日志 append-only，不得改写已结算条目。
- **注意**：本阶段仍不写 LLM 调用代码；M6（结构化清洗）与 M10（token 计数）只在未来真的引入 LLM 审计时启用，不在本阶段实施。

## 第三阶段：隔离沙盒红队实验（须用户另行批准）

- **准入条件**：第二阶段验收通过，**且用户在主聊明确批准本阶段**。无批准不启动。
- **交付物**：
  1. 沙盒目录（与 TAE 物理隔离）：LLM 审计员只读 TAE 输出文件（台账、审计报告、实验设计），产出"红队审计意见"文档。
  2. 意见处理规则：意见仅供参考，**不自动触发任何规则变更**；每条意见须经人工判定（命中真实问题 / 误报 / 无法判定）后登记。
- **验收标准**：沙盒运行期内，审计意见命中至少一个经人工确认的真实问题；且零条意见直接导致规则变更（意见到规则之间必须有人工批准环节）；TAE 文件 mtime 0 变动。
- **回滚方式**：关闭沙盒目录，删除 LLM 审计员配置；TAE 不受影响；已登记的意见保留为文档。
- **防呆**：沙盒无交易接口、无 TAE 写权限、无推送渠道；LLM 输出不进入任何信号文件；预算先行（token 计数，超支即停）；默认模型名须先映射到己方实际可用模型（审查未核实 `gpt-6-sol`/`gpt-6-luna` 可用性）。

## 不在路线图内（明确排除，未来重启须重新立项）

- LLM 信号接入 TAE（任何形式：评级、方向词、价格建议）。
- LLM 仓位建议、自动执行、实盘交易。
- 把 TradingAgents 的回测评分器（rating vs 5 日 alpha）用作收益证据。
- 把 LLM 自写反思写入我方记忆/日志。

## 各阶段与 TAE 的关系（强制隔离清单）

| 项目 | 第一阶段 | 第二阶段 | 第三阶段 |
|---|---|---|---|
| 改 TAE 代码 | 否 | 否 | 否 |
| 读 TAE 输出 | 否（只读审查文档） | 只读 | 只读 |
| 写 TAE 目录 | 否 | 否 | 否 |
| 调用 LLM | 否 | 否 | 否（沙盒内调用，但输出不进 TAE） |
| 调用交易接口 | 否 | 否 | 否 |
| 须用户另行批准 | 否（文档工作） | 否（验收后进入） | **是** |
