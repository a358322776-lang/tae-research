## 规则（与设计稿 F1–F11 一致）

### F1 趋势：200 MA 定偏向（持续偏向，非一次判定）

- 趋势指标：1H 收盘价的 SMA(200)。
- 触发 bar 收盘时判定：收盘 > SMA200 → 只做多；收盘 < SMA200 → 只做空；
  收盘恰等于 SMA200 → 不交易。
- 每根 bar 重新判定（持续偏向）；不设“趋势一旦判定不再重检”。

### F2 区域：四类均可作区域，统一为“带”

- 区域半宽：0.25 × ATR(14, 1H)（触发 bar 时点值）。区域带 = 水平位 ± 半宽。
- (a) 摆动水平位：已确认摆动高／低（swings k=2，摆动 bar 索引＋2 ≤ 当前 bar
  才算确认），摆动 bar 在当前 bar 之前 200 根内。
- (b) 50 MA 动态区域：带 = SMA(50) ± 半宽。
- (c) 趋势线：上升趋势线取最近两个已确认摆动低（后者高于前者）连成的直线，
  向前延伸；下降趋势线取最近两个已确认摆动高（后者低于前者）。
  趋势线有效直至被破：上升线在某根收盘 < 线值 − 半宽时失效，
  失效后须出现新的一对摆动点才重画；下降线镜像。
  趋势线带 = 线值 ± 半宽。
- (d) 翻转位：已确认摆动低被破（某根收盘 < 摆动低 − 半宽）后未收复
  （未出现收盘 > 摆动低 ＋ 半宽），且摆动 bar 在 200 根内 → 该位作阻力带；
  摆动高被破后未收复 → 作支撑带。收复后翻转条目移除（该位回归普通摆动位）。
- 方向属性：摆动低、上升趋势线、翻转高（被破阻力转支撑）为支撑型
  （仅多头可用）；摆动高、下降趋势线、翻转低（被破支撑转阻力）为阻力型
  （仅空头可用）；50 MA 为中性（双向可用）。
- 汇合（confluence）：触发时若形态极值同时与 ≥2 个不同类型区域带相交，
  记汇合标志 = 是；汇合只作描述性记录，**不是过滤条件**。
  汇合计数只计方向相符的带。

### F3 “来到区域”：拒绝而非穿破

- 设形态极值 E：看多形态取形态各 bar 的最低 low；看空形态取最高 high。
  设触发 bar 收盘 C、区域带 [zb, zt]。
- 看多需同时满足：(i) E 与带相交，即 (E ∈ [zb, zt]) 或 (E < zb 且 C ≥ zb)；
  (ii) C ≥ zb。
- 看空镜像：(i) (E ∈ [zb, zt]) 或 (E > zt 且 C ≤ zt)；(ii) C ≤ zt。
- 触及判定只计方向相符的带：多头只计支撑型与中性带；空头只计阻力型与中性带。

### F4 触发形态集（10 个方向形态，5 族）

- 看多：bullish engulfing、hammer、dragonfly doji、tweezer bottom、morning star。
- 看空：bearish engulfing、shooting star、gravestone doji、tweezer top、evening star。
- 多根形态以最后一根收盘为触发 bar；形态极值 E 按 F3 定义取形态各 bar 的极值。
- 同一 bar 出现同方向多个形态 → 计一次信号（记录全部匹配形态，不重复开单）。
- 同一 bar 不可能同时出现看多与看空形态（定义互斥）。

### F5 入场：触发 bar 收盘市价

- 入场价 = 触发 bar 收盘价，市价（taker）。
- 同一时间最多一单；持仓中出现的新信号一律忽略（不加仓、不反手）。
- 出场后无冷却。

### F6 止损：形态极值外留 buffer

- 看多：止损 = 形态最低 low − 0.5 × ATR(14, 1H)（触发 bar 时点值）。
- 看空镜像：止损 = 形态最高 high ＋ 0.5 × ATR。
- 止损距离 = |入场价 − 止损价|；R 的分母即为止损距离。

### F7 出场：摆动目标＋20 MA／前根收盘 trailing，先到者胜

- 出场判定从入场 bar 之后第一根 bar 开始（入场 bar 本身不判定出场）。
- (a) 摆动目标 TP：入场时按触发 bar 的区域集合定死，不随区域演变而移动。
  看多：TP = 阻力型＋中性带中带底 > 入场价的最小带底；无此带则无 TP。
  看空镜像：TP = 支撑型＋中性带中带顶 < 入场价的最大带顶；无此带则无 TP。
  TP 触发：看多为某根收盘 ≥ TP；看空为收盘 ≤ TP；成交价为该根收盘。
- (b) Trailing：看多为某根收盘 < SMA(20) 或收盘 < 前一根 bar 的 low；
  看空镜像（收盘 > SMA(20) 或收盘 > 前一根 bar 的 high）。
- 同根优先级：止损 > TP > trailing。
- 止损触发：看多为某根收盘 ≤ 止损价；看空为收盘 ≥ 止损价；成交价为该根收盘。
- 无时间过期。无保本移动。

### F8 仓位与风险（新增，非教学）

- 单笔风险固定 2%（风险预算 = 账户 × 2%；R 计算与规模无关）。
- 数量 = 风险预算 ÷ 止损距离；隐含杠杆 = 名义 ÷ 账户；隐含杠杆 >20x 跳过。
- 最小名义检查：ETH 20U；名义 <20U 跳过。

### F9 成本与资金费（新增，非教学）

- 入场 taker 0.05%、出场 taker 0.05%（全部出场均为收盘市价，无 maker 项）。
- 滑点档位：0／0.05%／0.1% 逆势，同时作用于入场价与出场价。
- 资金费：用镜像 fundingRate 实际历史（真实时间戳分页，不假设固定 8h 网格），
  持仓期间每个缴费时间戳按名义计入（多头费率为正时付费、为负时收费；
  空头反向）。

### F10 执行纪律（新增，非教学）

- 仅已收盘 bar；摆动点须确认（索引＋2 ≤ 当前 bar）；
  均线用截至触发 bar 的收盘（含触发 bar 本身，决策时点已知，无未来函数）。
- 无盘中填充假设；无跳空缺口模型（滑点档位仅部分覆盖）。

### F11 明确排除（不在忠实版内）

- 突破–回踩–收复序列、归簇带构造、EMA50 退出、5m 触发、15m 带、
  48 根过期、2h 冷却、合并 K 线读图规则、保本移动。

### 形态数值定义（与设计稿 §3 一致）

设单根 bar：O 开盘、C 收盘、H 最高、L 最低、body = |C − O|、range = H − L、
上影 = H − max(O, C)、下影 = min(O, C) − L。ATR 取触发 bar 的 ATR(14, 1H)。

| 形态（方向） | 数值定义 |
|---|---|
| Bullish engulfing（多） | 前根收跌；本根收涨；O < C1 且 C > O1（严格包覆实体，无宽容）。 |
| Bearish engulfing（空） | 镜像：前根收涨；本根收跌；O > C1 且 C < O1。 |
| Hammer（多） | C > O；body > 0；下影 ≥ 2 × body；上影 ≤ body。 |
| Shooting star（空） | C < O；body > 0；上影 ≥ 2 × body；下影 ≤ body。 |
| Dragonfly doji（多） | body ≤ 0.1 × range；上影 ≤ 0.1 × range；下影 ≥ 0.5 × range。 |
| Gravestone doji（空） | 镜像：body ≤ 0.1 × range；下影 ≤ 0.1 × range；上影 ≥ 0.5 × range。 |
| Tweezer bottom（多） | 两根：\|L − L1\| ≤ 0.2 × ATR；本根收涨（C > O）。前根方向不限。 |
| Tweezer top（空） | 镜像：\|H − H1\| ≤ 0.2 × ATR；本根收跌（C < O）。 |
| Morning star（多） | 三根：第一根收跌；第二根小实体（\|body2\| ≤ 0.5 × \|body1\|）；第三根收涨且 C > 第一根实体中点。 |
| Evening star（空） | 镜像：第一根收涨；第二根小实体（同上）；第三根收跌且 C < 第一根实体中点。 |

注：body = 0 的锤／射击一律不作 hammer／shooting 信号（D5）；
body ≈ 0 且影线符合 doji 定义者归 doji 类。
