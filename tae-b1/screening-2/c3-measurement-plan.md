## 1. 预注册：观测窗口、采样频率与固定宇宙

- **T0** = 用户批准执行的确认时间（UTC），记入执行记录；一切“当前值”以 T0 为准。
- **固定观察宇宙**（T0 时刻 exchangeInfo 列出的全部季度合约，窗口内不新增）：
  USDT-M（fapi）：BTC/ETH × 当季／次季；COIN-M（dapi）：BTC/ETH × 当季／次季。共 8 个合约。
- **窗口**：T0 → T0＋28 天。**采样**：每日 00:00／06:00／12:00／18:00 UTC，4 次／天，112 快照／合约。时刻固定，不得事后挑选时段。
- **到期处理**：某合约在窗口内到期 → 观测至到期为止，不拼接、不展期、不补新合约；到期后该合约序列终止。
- **完整性门**：每合约 ≥100／112 快照（≥89%）否则该合约判证据不足；缺失只记原因、不插补；深度快照不可事后回补（历史深度不存在）。
- **现货腿**：币安现货 BTCUSDT／ETHUSDT（bookTicker＋depth），与期货快照同一秒级时间戳；不得用永续 mark 价代替现货价。

## 2. 预注册：可执行报价测量定义（不用中间价估算利润）

- 每快照字段：时间戳、期货 bid／ask＋双边深度、现货 bid／ask＋双边深度、mark／index（仅记录，不用于收益）、exchangeInfo 快照哈希。
- **可执行入场基差**（真实买卖方向：现货按 ask 买入、期货按 bid 卖出）：
  `b_exec = F_bid / S_ask − 1`。名义量 S 下用深度 VWAP：
  `F_bid(S)` = bid 侧按量加权均价，`S_ask(S)` = ask 侧按量加权均价；
  S ∈ {50U，100U，200U} 名义（1000U 纸面口径的 5%／10%／20% 腿）。
- **年化**：`b_ann = b_exec × 365 / D`，D = 快照日到交割日的日历天数（以 exchangeInfo deliveryDate 为准）。
- **价差**：`spread% = (ask − bid) / mid`（mid 仅作价差分母，不用于收益）。
- **深度与可交易规模**：带内 = 买侧 [bid×0.999，bid]／卖侧 [ask，ask×1.001]；
  深度名义 = Σ price×qty（带内）；**可交易规模 = min（现货腿带内名义，期货腿带内名义）**；
  报告每合约的中位与 p10（USDT 名义口径）。
- **历史交割结算残差**：过去 4 个季度到期／资产／venue；
  `resid = (settlement_price − S_bid_结算时刻首个可执行买价) / S_bid`，取 |resid| 中位。
  C3 原文用中间价，本次按用户要求改用可执行报价，**阈值 0.30% 不变**，口径差异在报告中单列。
  结算价以交易所公布为准；若某到期无官方结算价或无结算时刻可执行现货报价，该到期不计入。

## 2A. 现金流分解：四桶与防重计规则（修订版 v2 新增）

现货买入、期货卖出、持有至交割的完整现金流（每单位数量 Q，主口径 L=1x）：

`净 P&L = (F_bid − P_settle)×Q ＋ (S_bid_T − S_ask)×Q − 费用_A − 费用_B`
`＝ 入场基差_$ − 残差_$ − 费用_A − 费用_B`

其中入场基差_$ = (F_bid − S_ask)×Q；残差_$ = (P_settle − S_bid_T)×Q；
P_settle 为交易所公布的交割结算价，S_bid_T 为交割时刻现货可执行买价。

| 桶 | 内容 | 发生时点 | 计入位置 |
|---|---|---|---|
| A 交易手续费 | 入场现货 taker ＋ 入场期货 taker ＋ 交割后现货卖出 taker | t0 与 T | 分子扣减（一次） |
| B 结算费用 | 交易所交割结算费（仅当 T0 核实官方文档确认存在时） | T | 分子扣减（一次） |
| C 基差残差 | 结算价与现货可执行卖价之差（P_settle − S_bid_T） | T | 分子扣减（一次；期望值取历史 \|resid\| 中位作保守准备） |
| D 残差准备金 | ρ×名义，ρ = 历史 \|resid\| 中位 | t0 预留 | 分母（资本），不进分子 |
| E 保证金占用 | 现货现金 ＋ 期货腿保证金（见 §3.3 分母） | t0 占用 | 分母（资本） |
| F 期中 MTM | 持有期期货与现货浮盈亏（交割时轧差） | 持有期 | 不计 P&L，只进强平分析（§3） |

**防重计规则**：

- **R1 价差只计一次**：入场基差用 bid／ask 已含顶档价差，不得另加“滑点／价差成本”。
- **R2 残差只扣一次**：残差_$ 在分子扣一次；准备金只进分母；同一笔残差不得既扣分子又扣分母的收益。
- **R3 准备金不是预期亏损**：ρ 是缓冲资本（应对残差不利实现），不是 P&L 扣减；
  期望净基差扣的是历史 \|resid\| 中位（桶 C），准备金（桶 D）不得重复扣。
- **R4 结算费只计一次**：仅当 T0 核实官方文档确认存在时计入桶 B；期货交割平仓本身不是一笔交易，不得另计期货出场 taker。
- **R5 资金费为 0**：交割合约无资金费结算，不得把永续资金费导入计算。
- **R6 期中 MTM 不计 P&L**：持有期浮盈亏在交割时轧差，期中波动只进强平分析，不得作为已实现损益。

时序：t0（现货买入现金流出、期货保证金划入、手续费 A 入场部分）→ 持有期（无资金费；保证金余额随 MTM 变动）→
T（期货按结算价现金交割、现货按 bid 卖出、结算费 B、手续费 A 出场部分、保证金解冻、准备金释放）。

## 3. 预注册：合约规格、保证金、资金需求、手续费、强平核实清单（T0 时刻取证）

- **合约规格**：exchangeInfo 全量快照（fapi＋dapi，哈希存档）：合约乘数／面值、最小名义、数量步进、tick、交割日、结算规则、交割费用有无。
- **手续费**：T0 时刻以币安官方费率表为准并存档（日期＋URL＋数值）：现货 taker、期货 taker、交割结算费（有无以官方文档为准，**不得假设为 0**）；VIP0 口径；费用全额计入净基差（桶 A／B）。

### 3.1 USDT-M（稳定币保证金）

- **实际资金占用**：现货腿 = 全额 USDT 现金（S_ask×Q）；期货腿 = USDT 保证金（名义／L，主口径 L=1x）；
  另加手续费缓冲与残差准备金（见 §3.3 分母）。保证金资产为 USDT，**无币价波动问题**（USDT 脱锚为尾部风险，列出、不量化）。
- **保证金钱包隔离**：现货钱包（USDT 现金）与合约钱包分离；期货腿预注册 **isolated（逐仓）保证金模式**，
  保证金 ring-fenced；现货浮盈**不自动**转为期货保证金，期中价格上冲须手动划转或预留缓冲。
- **强平风险**：空头余额 B(r) = M − N(r−1)，维持保证金 MM(r) = mm×N×r（r = P/P0，mm 分档取值）；
  强平点 r = (M/N ＋ 1)/(1＋mm)，即 L=1x 时 r = 2/(1＋mm)，L=2x 时 r = 1.5/(1＋mm)；
  mm=0.5% 时 1x 强平距离约 ＋99%，2x 约 ＋49%（§6 手算例核对）。手续费从保证金扣除，计入余额。
  非价格触发项与 COIN-M 相同（划转、ADL、社会化亏损、结算异常）。

### 3.2 COIN-M（币本位保证金）

- **实际资金占用**：现货腿 = 币（现货钱包持有 BTC／ETH）；期货腿 = 币本位保证金（名义／L，以币计）；
  另加手续费缓冲与残差准备金（币计，USDT 价值按 T0 价格折算后计入分母并注明汇率时点）。
- **保证金钱包隔离**：与 USDT-M 相同，现货钱包与合约钱包分离，现货浮盈不自动补期货保证金；
  另有币种隔离：BTC 现货不能直接充当 ETH 合约保证金（分币种钱包），双资产 carry 须分币种核算。
- **保证金资产价格波动**：无摩擦模型下，币本位余额与维持保证金同按 1/P 缩放、比值恒定，
  **价格单因子不触发强平**（C3 修订 2 已证）；手续费以固定币量扣除打破缩放，强平价约 2000×P0（可忽略但非无穷）；
  现货腿币价下跌时币本位保证金的 USDT 价值缩水，但债务同为币计价，不构成额外 USDT 强平——USDT 口径的“缩水”不得重复计为亏损。
- **强平风险**：沿用 C3 修订 2 已推导公式：1x 无摩擦无价格强平、计费后约 2000×P0；
  2x 中性配置强平边界 mm 0.5% 时 1.99×P0（约 ＋99%）；非价格触发项：钱包划转、ADL、社会化亏损、结算异常、长期持仓费用累积。
  主口径不预设期中缓冲；如采用缓冲，计入分母并披露。

### 3.3 承诺资本年化收益的分母（定义，唯一口径）

`D_cap = S_ask×Q（现货现金）＋ N_fut/L（期货腿保证金，N_fut = F_bid×Q）＋ F_total（全部手续费，桶 A＋B）＋ ρ×N_spot（残差准备金，ρ = 历史 |resid| 中位）`

`年化净收益 = 净 P&L × 365/D ÷ D_cap`，D 为持有天数。分母四项缺一不可；
准备金进分母、不进分子（§2A R2／R3）；2x 只作算术换算标注，不作主口径。
分母以 USDT 计；COIN-M 的币计部分按 T0 时刻价格折算并注明。

## 4. 预注册：净基差与判定规则（K-C3-1／K-C3-2／K-C3-4）

- **净基差**（承诺资本口径，按 §2A 四桶分解）：
  `净 P&L(S) = 入场基差_$(S) − 残差_$(S) − 费用_A − 费用_B`（残差只扣一次，准备金不进分子）；
  `年化净收益 = 净 P&L(S) × 365/D ÷ D_cap`，D_cap 定义见 §3.3。
  若残差证据不足，net 标注“未扣残差”，**不得判 K-C3-1 通过**。
- **R**：FRED DGS3MO 窗口期均值（分析时取值，记录数据 vintage）。
- **K-C3-1（R 门槛）**：通过 = 中位年化净基差 ＞ R；失败 = ≤ R；证据不足 = 快照不足／费用未核实／残差未扣。
  **失败 → 停止 CA-1**，不得降成本假设、不得调阈值。
- **K-C3-2（执行性）**：通过 = 价差中位 ≤ 0.20% 且双腿带内深度中位 ≥ 10×最小单位名义；
  失败 = 任一 breach；证据不足 = 深度数据不全。失败仅淘汰含该远月腿的变体（按注册原文）。
- **K-C3-4（结算残差）**：通过 = 历史 |resid| 中位 ≤ 0.30%（≥3 个到期／资产／venue）；
  失败 = ＞ 0.30%；证据不足 = 可检索到期 ＜3 个或无可执行现货报价。失败 → 持有至交割变体淘汰。
- **稳定性描述**（不改判定）：报告 net ＞ R 的快照占比与 net 的 p25，仅描述，不设新阈值。
- **CA-1 总 verdict**：通过 = 至少一个（资产 × 期限 × venue）组合同时通过三项；
  失败 = 无组合通过、且至少一组合证据完整而 K-C3-1 失败；
  证据不足 = 无组合证据完整。

## 6. 固定价格手算例（核对公式，修订版 v2 新增）

设定（固定价格，仅核对算术，不代表市况）：BTC，S_ask = 80,000，F_bid = 80,800，Q = 0.0125 BTC，
D = 57 天，L = 1x，mm = 0.5%，ρ = 0.20%。
费率取标注的 VIP0 taker 假设值（现货 0.10%，期货 0.05%，结算费 0 待 T0 核实）——
仅用于核对算术，**不是成本主张**；测量时以 T0 核实的费率表为准，不得用更乐观假设。

- **Step 1 入场基差**：(80,800 − 80,000) × 0.0125 = **$10.00**；名义：现货 $1,000.00，期货 $1,010.00。
- **Step 2 费用**：入场现货 0.10% × 1,000 = $1.0000；入场期货 0.05% × 1,010 = $0.5050；
  出场现货 0.10% × (81,900 × 0.0125 = $1,023.75) = $1.02375；结算费 $0（待核实）；合计 **$2.52875**。
- **Step 3 交割**：P_settle = 82,000，S_bid_T = 81,900；
  期货 P&L = (80,800 − 82,000) × 0.0125 = −$15.00；现货 P&L = (81,900 − 80,000) × 0.0125 = ＋$23.75；
  残差 = (82,000 − 81,900) × 0.0125 = **$1.25**。
- **Step 4 净 P&L（两种算法一致）**：直接法 −15.00 ＋ 23.75 − 2.52875 = **$6.22125**；
  分解法 10.00 − 1.25 − 2.52875 = **$6.22125**；差 0，分解成立。
- **Step 5 分母**：D_cap = 1,000.00（现货）＋ 1,010.00（期货保证金）＋ 2.52875（费用）＋ 2.00（准备金 ρ×名义）
  = **$2,014.53**。
- **Step 6 年化**：6.22125 ÷ 2,014.53 × 365/57 = **1.98%/年**（毛基差年化 3.18%/年）；
  对照 R 4.18% → 本例 K-C3-1 失败（示例性质，不作 verdict；仅展示承诺资本稀释：毛基差 6.4% 年化 → 净 1.98%）。
- **Step 7 强平距离**（USDT-M，mm = 0.5%）：1x：r = 2/1.005，距离 **＋99.00%**；
  2x：r = 1.5/1.005，距离 **＋49.25%**。COIN-M：1x 计费后约 2000×P0，2x 中性 1.99×P0（C3 修订 2）。
- **核对清单**：价差计一次 ✓（bid／ask 内含）；残差扣一次 ✓（分子 $1.25，准备金只进分母）；
  结算费 0 有标注 ✓；资金费 0 ✓（交割合约无资金费）；MTM 未计入 P&L ✓；
  杀线未动 ✓；成本未放宽 ✓（taker 标准费率，非 maker 优惠）。
- **本例不证明什么**：单组固定价格，无分布、无统计意义；仅核对公式、分母与防重计逻辑。
