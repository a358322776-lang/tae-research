## H6 成本口径 · 更正

**core.py 实际实现：**

```python
fee=0.0010,   # taker per side
slip=0.0005,  # slippage per side
cost = fee + slip = 0.0015     # 单边 15bp
net  = gross - turnover * cost  # turnover 为两腿权重变化绝对值之和
```

- **15bp 是单边**（10bp 手续费 + 5bp 滑点）
- 一次完整往返（开 + 平）= **30bp**
- 我的成本档 6/15/30/50bp **全部是单边口径**，报告中未标明，**这是缺陷**
- 与官方费率对照：币安现货 VIP0 taker = **0.10%**（10bp），我用的正是这个；maker = 0.10%（非 VIP 不返佣）。滑点 5bp 对日线级别、中小资金合理，但**未按币种流动性分层**——小币实际滑点会更高。

**更正后的读法**：报告里"15bp"应读作"单边 15bp / 往返 30bp"。
