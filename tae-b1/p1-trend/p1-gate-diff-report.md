## 0. 结论先行（五句话）

1. **六合约现在都在交易，行情类 API 本机实测通**：SPY/QQQ/TLT/GLD USDT 永续＋BTC/ETH，
   合约层面无 API 禁用字段；“原则上具备六资产研究条件”成立，但只到“研究条件”为止。
2. **历史长度是最大断层**：SPY/QQQ 合约仅约 57 天、GLD 约 135 天、TLT 约 273 天——
   12 个月形成期在合约价格上根本算不出来（SPY/QQQ 连一个形成期都不够）。
   机制验证只能继续用 ETF 现货历史（Yahoo adjclose），合约历史只能做执行验证；
   两轨必须分开，绝不能把现货历史收益冒充成合约历史收益。
3. **流动性两极分化**：SPY/QQQ/BTC/ETH 深且价差极小；TLT/GLD 极薄且价差大
   （快照价差 TLT 0.23%、GLD 1.00%，而草案中央滑点档只有 0.05%）。
   统一滑点档对 TLT/GLD 不够用，必须改成分资产档位或限定执行窗口（审查时定）。
4. **56U 下等权无法精确执行**：单腿目标约 9.33U 时，SPY/QQQ/TLT/GLD/BTC 最近整数张
   偏差 −12%～−23%，ETH 整数张偏差 +149%；ETH 能否小数下单是决定性未知项。
   即使 ETH 可小数，最近似总额也只有约 47.85U（85% 仓位），剩余为量化现金拖累。
5. **两处费用／规则打架＋一处未确认**：官方 TradFi VIP0 taker 0.05% 与合约 API 字段
   taker 0.075% 不一致（见 §4.1）；CFD 产品的分红调整规则不能直接套用到 USDT 永续
   （见 §6）；ETH 小数下单、美收盘时段价差、跟踪误差、地区资格／API 权限均未确认（见 §9）。
   在 §9 清单补齐前，探索回测门禁仍未过——门禁换了通道，没取消。

## 3. 交易时段与价格跟踪

### 3.1 平台 24/7 ≠ 标的全天候有报价

Gate 帮助中心对美股期货指数价格的说明（按美东时间 ET）：
盘前 04:00–09:30、常规 09:30–16:00、盘后 16:00–20:00、夜间／休市 20:00–次日 04:00
及周末节假日；对有夜间行情支持的高流动性热门标的（大型科技股、主要 ETF），
夜间继续从外部夜间流动性商取实时动态报价；无夜间支持的标的则沿用盘后最后一价
（静态 carries forward），直至下一交易时段。

- 对草案 F3 的冲击：草案的“次日收盘执行”在 IBKR 语境下指美股收盘；
  在 Gate 语境下必须重定义（D-G1，见 §8）：(a) 维持美东 16:00 收盘价执行
  （SPY/QQQ 可行，TLT/GLD 需复测收盘价差）；(b) 改用 Gate UTC 日收盘（00:00 UTC）
  ——简单统一，但信号日（美股月末）与执行日（UTC 月末）可能差一天，
  且机制序列（美收盘）与执行序列（UTC 收盘）之间产生时差跟踪缺口；
  (c) 改用下一美股开盘执行——价格又不同。三者只能选一，冻结前定，
  且选定后须用同口径价格重算成本（不得混用）。

## 4. 成本模型差异（对照登记 §3、草案 F6）

### 4.1 手续费：官方口径与合约 API 字段打架——未裁决

- Gate 官方学习文章：VIP0 永续 maker 0.020% / taker 0.050%；
  第三方转述的 Gate 专项费率表：2026-09-01 起 USDT-M TradFi 永续（股票／金属／指数等）
  VIP0 maker 0.0200% / taker 0.0500%。两路口径一致，指向 **taker 0.05%**。
- 但合约 API 每个合约字段均为 maker −0.010% / taker 0.075%。
  该字段含义未核实（可能是合约默认费率、做市返佣口径或其他口径），
  **不得直接当作用户实际费率**，也不得直接否定官方费率表。
- 处理（审查时定，冻结前裁决）：成本模型同时携带两档——
  中央档 taker 0.05%（官方口径）、保守档 taker 0.075%（API 字段口径）；
  最终以用户 App 内订单确认页的 all-in 费率（结合其 VIP 等级）为准。
  在此之前，任何“Gate 成本低于 IBKR”或反之的结论均不成立。
- 另两项简化（Gate 路线独有）：(a) **借券项消失**——永续原生可做空，
  登记 §3.2 的 `borrow_term` 在 Gate 路线为 0，草案开放问题 Q4（借券复核）在 Gate
  路线下不再是门禁（但若将来切回真股／IBKR，Q4 立即恢复）；(b) **无最小佣金项**——
  Gate 期货费率为纯百分比，公开费率表未见 `c_min` 式最低佣金，
  登记 §3.2 的 `max(c_rate×N, c_min)` 在 Gate 路线退化为 `c_rate×N`
  （仍以订单确认页为准）。

- **全部腿改为 USDT 保证金永续**：草案 F4 的“永续腿保证金＝名义（1x）”在 Gate 路线
  扩展到全部 6 腿；总名义 ≤ 组合价值的上限不变，但须 reinterpret 为：
  各腿逐仓保证金之和＋手续费／资金费预留 ≤ 期货账户 USDT 余额。
- **逐仓 vs 全仓未定**：草案未写明逐仓／全仓。Gate 统一账户下若用全仓，
  一腿亏损会侵蚀共享保证金；若用逐仓，各腿互不传染。审查时须定（D-G5），
  本报告倾向逐仓 1x（与草案“保证金＝名义”最接近），但只是倾向、不是决定。
- **强平距离（1x 近似，不含费用／资金费侵蚀）**：强平距离约等于 1 − 维持保证金率
  （多头方向近似）：SPY 约 99.2%、QQQ 约 99%、TLT 约 99%、GLD 约 97.5%、
  BTC/ETH 约 99.7%。在价格正确的前提下 1x 强平风险可忽略；真正的尾部风险
  不是正常波动，而是 §6 的错误调整类平台操作风险（见 BEN 案例）与极端跳空缺口。
- **调仓顺序未写**：草案 F3 未规定换腿时先平后开还是一起下单。
  Gate 路线下换腿若先开新腿再平旧腿，会短暂双倍占用保证金；
  冻结时须写死“先平后开”（D-G5），否则小资金下可能因保证金不足导致换腿失败。
- **未配置现金**：草案 F4 的现金 0% 在 Gate 路线下指期货账户内未用作保证金的 USDT
  （默认不生息；若开通任何生息／理财产品属另一产品，不得默认计入收益）。
- **退市规则改写**：草案 F1 的 ETF 退市规则在 Gate 路线下对应的是“合约下线／暂停交易”
  规则（合约 `in_delisting` 字段、Gate 公告），而非 ETF 退市公告；
  冻结时须把退市条款改写为合约下线条款（D-G5 附带项），不得直接沿用 ETF 退市文字。

## 6. 分红调整：CFD 的规则不能直接套用到 USDT 永续（未确认，最高风险项之一）

- **产品线区分（必须先分清）**：Gate 至少有两条 TradFi 产品线——
  (a) USDT-M 永续期货（本报告核查对象，`contract_type=stocks`，8h 资金费，平台 24/7）；
  (b) TradFi CFD（按手数计佣金、按掉期／三倍掉期计过夜费、非 24/7、跟随标的市场时段）。
  Gate 帮助中心《CFD Fee Calculation》中的 USDT 分红调整（多头收、空头扣、
  仅除息日持仓、自动入账、交易历史中显示为 Dividend Adjustment）**写的是 CFD 产品**，
  不得直接认定它同样适用于 USDT-M 股票永续。
- **股票永续确实存在分红调整机制（第三方报道，须审慎引用）**：
  据 cryptonews 报道，Gate BENUSDT 永续在 2026-09-30 一次计划内股票分红调整后
  65 秒内出现 92 笔强平；9-28 公告的调整额为 $0.33，而调整前一分钟合约标记价仅
  $0.000589（调整额约为价格的 560 倍）；随后自称 Gate 负责人的账号承认系同名资产
  搞错所致、已处理、用户无损失。该报道为第三方消息，未经 Gate 官方公告核实，
  但它证明两点：(a) 股票永续存在分红调整且会影响保证金与强平；(b) 错误调整
  是真实发生过的操作风险，不是理论风险。
- **ETF 永续的分红规则未确认**：SPY/QQQ（季度分红）、TLT（月度分配）、GLD（无分红）
  各自在 USDT 永续上的调整额、时点、扣缴、除息日清单，在本次查阅的 Gate 永续文档中
  **均未找到**。在确认前，成本模型必须把分红调整列为 **TBD 项、不得默认为零**；
  只要该项为 TBD，合约买入持有总收益与 Yahoo adjclose 总收益（分红再投资、无扣缴、
  无延迟）之间的等价关系即不成立——这是 §7 基准双轨的直接原因。
- **扣缴数字不得乱用**：另有第三方报道称 Gate 分红结算按 10% 扣缴——
  该报道描述的是 Gate 分红结算批次（可能指向 Gate Stocks），**未核实适用于 USDT-M 永续**，
  本报告不采用该数字，冻结前须以 Gate 永续合约细则或官方客服确认为准。
- **量级提示（仅用于判断重要性，不是成本假设）**：SPY 季度分红约 $1.8／股
  （相对 $772 约 0.23%／季）；若调整正确且及时，1x 下的分红缺口对保证金影响极小；
  风险不在正确调整，而在错误调整与扣缴／延迟造成的跟踪缺口。
