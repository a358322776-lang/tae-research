## 2. 成交模型（执行器真实规则 + 补充加严）

- 入场：LIMIT maker，价格 = 信号根 15m 收盘价（tick 取整，ETHUSDT tick 0.01，影响可忽略）；有效期仅下一根 15m（信号 bar 之后的第一根），到期未成交 → 撤单记 MISSED，部分成交按已成交量挂止损（R 与规模无关，故只建模成交/未成交二值）。
- 成交三档（成交价恒为限价，排队因素无法从 K 线观测，穿透档即为保守代理）：
  - T0 触及：多头下一根 low ≤ 限价 / 空头 high ≥ 限价；
  - T1 穿透 0.05%：多头 low ≤ 限价×(1−0.0005) / 空头 high ≥ 限价×(1+0.0005)；
  - T2 穿透 0.1%：同理 0.001。
- 止损排序铁律：止损只能在成交之后判定。回测原 exit 若落在成交 bar（信号 bar 后第一根）内且为止损触发，则用 5m 粒度校验：止损 5m 根必须严格晚于成交 5m 根；早于或同根 → 原 exit 作废，从下一根 5m 起按原规则重算出场（每根 15m 内先 3 根 5m 判止损、再 15m 收盘判 EMA）。
- EMA entry-bar 规则（回测与执行器的实质口径差，本审计已纠正）：执行器 find_ema_exit 跳过 entry bar，且 entry bar = 首成交 bar（= 成交 bar i+1）；回测按纸面规则只跳过信号 bar（i），故回测在 i+1 收盘的 EMA 出场在执行器下全部无效，一律从 i+2 起重算（止损与 EMA 均从 i+2 起判；i+1 内经 5m 校验无止损触及，故从 i+2 起判止损无遗漏）。
- 本样本实测：成交 bar 内止损 3 单经 5m 校验排序全部有效（成交 5m 根均为 0，止损 5m 根为 1 或 2），无需重算；成交 bar 内 EMA 出场 20 单（T0）全部按上条从 i+2 重算（T1/T2 档中同类重算单数分别为 15 / 12 单）；止损排序违规 0 起。EMA entry-bar 修正对 T0 滑点 0 档总 R 的影响约 +0.55R（重算前后内部对照），不是决定性因素——真正吃掉期望的是费用与尾部集中（见 §7）。
- 出场执行：止损 = Algo STOP_MARKET（市价，taker）；EMA 出场 = 市价平仓（place_market，taker）。回测原 EMA 出场价取触发根收盘价，本审计沿用（事后检测的实际成交价应为下一根开盘附近，此处为偏乐观假设，见 §6 缺口）。

## 3. 费用与资金费口径（逐单按该单自己的止损距离算，绝非固定 R 数）

- 公式：费用 R = 费率% ÷ 该单止损距离%。例：往返 0.07%、止损距离 0.5% → 扣 0.14R；止损距离 0.2% → 扣 0.35R。止损越紧，费用吃掉的 R 越多。
- 入场 maker 0.02%（仅成交的单）；出场 taker 0.05%（止损触发与 EMA 出场均为市价）。精确式：入场费用 R = 入场价×0.02% / 止损点数；出场费用 R = 出场价×0.05% / 止损点数。
- 注意：执行器限价单为普通 LIMIT GTC（无 postOnly），下单瞬间若市价已穿过限价，成交可能是 taker 而非 maker；本审计按任务口径统一计 maker 0.02%，真实费用只可能比本审计更高（见 §6）。
- 资金费：ETHUSDT 8h 结算（00/08/16 UTC），按每单持仓期内覆盖的结算次数、方向逐单计入（多头付正费率、空头收正费率），名义按入场名义计（持仓期价格变动导致名义漂移未计，影响量级 < 资金费本身，见 §6）。风险 U = 2% × 56.16U = 1.1232U；名义 = 风险 U / 止损距离%。
- 滑点：止损出场 adverse 三档 0 / 0.05% / 0.1%（出场价向不利方向推）；EMA 出场按收盘价计、无滑点（假设，见 §6）。
