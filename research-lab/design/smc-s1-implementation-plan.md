## 4. 风险清单

- **R1（阻塞，第二批）— 无 1m 数据**：任务书 §三 要求 1m 模拟
  成交，workspace 无 1m 缓存。选项：(a) 拉取有界窗口 1m
  （如 2023 年起，约 150 万根，需评估镜像限流与存储）；
  (b) 降格为 5m 成交模拟 + 显式保守假设标记。须在第一批
  execution 接口定型前决定，否则接口返工。
- **R2（设计）— 成本模型重复**：另写成本函数必致口径分歧；
  已定为薄适配复用，见 §1.3。
- **R3（设计）— 前视偏差面广**：Pivot 右 2 根、BOS 收盘确认、
  FVG 识别时点、ATR 取值时点，四处都可能漏未来数据；第一批
  测试须逐处钉住，规则文档须写明每信号“决策时刻”与“可用
  数据截止时刻”。
- **R4（统计）— 复合过滤样本小**：1H 趋势 + BOS + FVG + 止损距
  离 0.5–3 ATR + 单仓，五重过滤后交易数未知；须事前定最小
  样本杀线（如训练段 <30 笔即 INCONCLUSIVE，不许放宽过滤凑数）。
- **R5（成本）— maker/taker 费率未核实**：统一模型现有规格只
  覆盖 B1/C5 约定；SMC 的 maker/taker 费率须对照币安官方费率
  表 / exchangeInfo 实测后写入密封规格，不得凭记忆填数。
- **R6（数据）— 资金费三项检查未做**：2026-11-04 已记录的后续
  改进——真实资金费接入前须补重复时间戳、异常数值、结算时间
  完整性检查；stitched funding 含 +5ms 级时间戳抖动（快照工作
  已见），SMC 成本审计前须先过三项检查。
- **R7（治理）— 最终测试集不存在**：B1 只有模板；冻结前任何
  “样本外”说法只能指训练/验证切分，不得冒充最终测试。
- **R8（定义缺口）— ATR 未定义**：任务书未定 ATR 周期与周期
  级别；须冻结后才编码（§5 D1）。
- **R9（定义缺口）— 保守成交假设未定义**：“触价不自动成交”
  须量化为可测试规则（§5 D3），否则回测乐观偏差无法审计。
